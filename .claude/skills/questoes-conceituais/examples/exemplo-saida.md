## Questoes

1. ( ) O Service Blueprint mapeia tanto as interacoes visiveis ao usuario
   (frontstage) quanto os processos internos que as sustentam (backstage).
2. ( ) O principio Once-Only estabelece que o cidadao deve fornecer os
   mesmos dados a cada novo servico publico que utiliza, para garantir a
   atualizacao das informacoes.
3. ( ) No Service Blueprint, a "linha de visibilidade" separa as acoes que o
   usuario percebe diretamente das que ocorrem nos bastidores da
   organizacao.
4. ( ) O frontstage de um servico digital corresponde exclusivamente ao
   codigo-fonte do sistema que processa a solicitacao do cidadao.
5. ( ) O principio Once-Only busca reduzir a redundancia de solicitacao de
   dados, permitindo que a administracao publica reutilize informacoes ja
   fornecidas anteriormente.
6. ( ) Um servico publico digital bem desenhado elimina totalmente a
   necessidade de qualquer processo backstage.
7. ( ) O backstage de um servico inclui atividades e sistemas que suportam
   a experiencia do usuario mas nao sao visiveis a ele.
8. ( ) O Service Blueprint e uma tecnica exclusiva para servicos
   inteiramente digitais, nao se aplicando a servicos presenciais.
